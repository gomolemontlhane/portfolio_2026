## Gomolemo Ntlhane — Portfolio 2026

Personal developer portfolio for **Gomolemo Ntlhane**, a Software Engineer and Electrical Engineer based in Johannesburg, South Africa.  
This is a single-page, fully responsive site built with HTML, CSS, and vanilla JavaScript.

### Features

- **Modern single-page layout**: Hero, About, Skills, Projects, Education, and Contact sections.
- **Custom interactions**: Custom cursor, scroll reveal animations, and active navigation highlighting.
- **Responsive design**: Optimized for desktop, tablet, and mobile viewports.
- **Project highlights**: Showcases recent work with space for GitHub and live demo links.
- **Contact & CV**: Direct email links, LinkedIn profile, and downloadable CV.

### Tech Stack

- **HTML5** for structure.
- **Modern CSS** (including responsive layout, grid, and custom effects).
- **Vanilla JavaScript** for interactivity (navigation, animations, and icon rendering).
- **Lucide Icons** via CDN.

### Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/portfolio_2026.git
   cd portfolio_2026
   ```

2. **Open the site**
   - Easiest: open the `index (1).html` file directly in your browser, **or**
   - Run a simple local server (recommended for development):
     ```bash
     # Python 3
     python -m http.server 8000
     # then visit http://localhost:8000/index%20(1).html
     ```

### Project Structure

- `index (1).html` — main single-page application (layout, styles, and scripts in one file).
- `assets/` — images and documents (profile pictures, project thumbnails, CV PDF, icons).

### Customization

- **Content**: Edit text (sections like About, Projects, Education, Contact) directly in `index (1).html`.
- **Projects**: Update project titles, descriptions, GitHub links, and live demo URLs in the **Projects** section.
- **Branding**: Replace images in `assets/` and adjust colors/typography in the `<style>` block of `index (1).html`.
